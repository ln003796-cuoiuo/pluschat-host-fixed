# Pluschat — полный комплект серверных файлов

Это полный набор файлов основного сервера Pluschat на базе `pluschat-host`, дополненный исправленными версиями файлов регистрации, входа, проверки API и необязательной 2FA. Исходный репозиторий `pluschat-host` не изменён.

## Перед заменой — обязательно

1. Сделай резервную копию **всех файлов хостинга** и базы данных.
2. **Не удаляй `confirm.php`** с твоими настройками. `bootstrap.php` теперь сначала использует `config.php`, а если его нет — пробует прочитать настройки из `confirm.php` (возвращаемый массив или распространённые имена переменных). Совместимость всё равно нужно подтвердить на самом хостинге: если имена переменных другие, подключение к БД не заработает до адаптации. Реальные пароли и ключи нельзя загружать в GitHub.
3. Не удаляй и не пересоздавай БД. Не запускай SQL миграции автоматически.
4. Архив намеренно не включает GitHub Actions workflow, установочную страницу `public/setup.php`, SMS/TextBee-сервис и миграцию телефонной SMS-верификации.
5. Сначала проверь комплект в тестовой папке/на тестовом стенде. Не заменяй рабочий сайт, пока не проверишь PHP и API.

## Как заменить файлы

1. Открой [ZIP-архив](https://github.com/ln003796-cuoiuo/pluschat-host-fixed/archive/refs/heads/main.zip) и распакуй его.
2. Скопируй содержимое архива в корневую папку серверного проекта на хостинге, сохраняя структуру каталогов.
3. Когда файловый менеджер спросит о замене файлов, разреши замену.
4. Сохрани свой существующий `config.php` и любые пользовательские файлы/секреты, которых нет в архиве.
5. Проверь настройки document root и `.htaccess`: запросы должны попадать в `public/index.php`.
6. Не импортируй `database/schema.sql` поверх существующей базы. Сначала сравни схему с `docs/DATABASE_UPDATE.md` и сделай резервную копию.
7. Проверь синтаксис PHP, затем регистрацию, подтверждение email, вход по email/нику, восстановление пароля, профиль, вызовы API и необязательную 2FA.

## Что включено

Полные каталоги и файлы модулей: `admin`, `calls`, `channels`, `chatprefs`, `chats`, `files`, `friends`, `groups`, `login`, `messages`, `notifications`, `password`, `polls`, `profile`, `register`, `saved`, `search`, `security`, `stories`, `topics`, `users`, а также `public`, `database`, `docs`, тесты, `.htaccess`, `.gitignore` и пример конфигурации.

В исправленном варианте сохранены обновлённые файлы `bootstrap.php`, `public/index.php`, модули `register` и `login`, `profile/api/Controller.php`, `security/api/Controller.php`, `security/services/TwoFactorService.php` и `tests/check-features.php`.

## Важные ограничения

Комплект собран из текущего исходного репозитория с указанными исправлениями; это **не гарантия**, что все функции прошли интеграционные тесты на твоём конкретном хостинге. Перед production-заменой нужно выполнить PHP lint и реальные тесты API, проверить совместимость с установленной схемой БД и почтовыми настройками. Не запускай тесты, которые создают/удаляют данные, на рабочей базе.
